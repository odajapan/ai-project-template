Getting started
===============

This project template is installed from ``pyproject.toml`` using an editable
install (``-e .``) plus optional "extras". The canonical install command is:

.. code-block:: bash

   pip install -e ".[dev,claude,jira]"   # or: make requirements

See the root ``README.md`` "Getting started" section for the full set of
installation methods (uv, pip/venv, Conda, Docker) and environment setup.
